## Top risks
1. **F-01 (critical):** `/` server HTML is "Loading tijothomas.dev..." plus an off-screen hidden SEO block (`app/page.tsx:263-271`, `app/layout.tsx:88-120`, `app/globals.css:156-162`).
2. **F-04 (high):** Repo profile data contains unverified and NDA-sensitive metrics, and three different bet365 titles. **Do not seed `content/*.ts` from it.**
3. **F-05 (high):** The root layout and global CSS are terminal-specific. ThemeProvider mutates `<html>`, body colours are terminal colours, and the mobile `html,body,main{100vh}` rule would break a long page at 360 px.
4. **F-02 (high):** `next@14.2.30` advisories. A full fix needs 15.5.29 or 16.4.6 (React 19), so this is an owner decision.
5. **F-03 (high):** `/api/chat` is an open LLM proxy. It has no rate limit or timeout, and the system prompt comes from the client. It stays live on `/terminal`.

## Top roadmap items for this feature
1. **N-2 Route split.** Use route groups `app/(site)` and `app/(terminal)`. Move the old `app/page.tsx` verbatim to `/terminal` together with ThemeProvider, JetBrains font and terminal CSS. Point VersionSelector "v1" to `/terminal`.
2. **N-3/N-4 Clean site root and hygiene.** No hidden SEO block, no `maximumScale`, `next/font` Space Grotesk + Inter, Vercel Analytics only. Lazy Supabase client. Tailwind globs plus vitest `@` alias and include globs. Bump to `next@14.2.35` if Q1 allows.
3. **X-1…X-4 Content and SEO.** `content/*.ts` from owner-confirmed facts. A server-rendered page with spec tests. Metadata, canonical, sitemap, robots, OG image and JSON-LD.

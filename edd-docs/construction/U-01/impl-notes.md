4. **SBOM without `npm sbom`:** npm 9.8.1 has no `sbom` command. `scripts/sbom.mjs` writes CycloneDX 1.5 from `package-lock.json` (purl, sha512, dev = `scope: excluded`). It adds no dependency and needs no network.
5. **Status `blocked`:** exit 78 from a gate is recorded as `blocked`. It never passes and fails the run when the gate is enforced. `scripts/require-tool.mjs` wraps gitleaks, so a missing binary is reported as `BLOCKED …` instead of a crash or a pass. CG10 is split into `CG10_audit`, `CG10_signatures`, `CG10_gitleaks_history`, `CG10_gitleaks_tree` and `CG10_sbom`, so that one blocked tool does not hide the others. The runner substitutes `{evidence}` and `{unit}` in `cmd`.
6. **CG2 vs CG7:** CG2 = `npm run lint && lint-report.mjs`. The report checks exit 0, ≤ 5 s, 0 warnings outside `terminalGlobs` and the ceiling, and writes `lint.json`. CG7 = `npm run lint`: the limits are error-level rules, so exit 0 means they pass. `check-complexity.mjs` is not built (SP-02 finding 3).
7. **CG5 diff coverage** (`check-coverage.mjs`): V8 coverage, then the added or changed lines of `git diff -U0 <merge-base main>` (working tree included) in `srcRoots`, tests excluded.

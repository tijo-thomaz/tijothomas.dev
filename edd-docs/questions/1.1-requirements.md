Answer each one with a letter. The recommended option is marked **(rec)**. The facts themselves are in `1.1-facts.md`. These questions are about rules and behaviour. Each one notes the FR/NFR/US it affects.

**RQ-01 "Coming soon" posts vs the `planned` rule** (FR-012, FR-027, US-08, US-11)
All 3 writing items in the mockup are "Coming soon". If they count as `planned`, the Writing section is empty in production while the city still has a "Writing" building.
- (a) **(rec)** Add a separate post status `coming-soon`. It is shown with a "Coming soon" badge and is not a link. Only `planned` is hidden by `SHOW_PLANNED`.
- (b) Treat them as `planned`, so they are hidden. The Writing section shows an empty-state line (C-15) and keeps its id, so the building link still works.
- (c) Treat them as `planned` and also hide the Writing section, nav link and building. This breaks the spec's city-link test unless the building is removed too.

- (b) Render neutral text ("Available on request" / "Details coming soon").
